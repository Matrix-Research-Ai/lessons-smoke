# Μαθήματα ΕΠΑΛ — βιβλιοθήκη

Αυτό το repo δημοσιεύει σχέδια μαθήματος μέσω του **Lesson Publisher**.
Η αρχική σελίδα (`index.html`) παράγεται αυτόματα από το `manifest.json`.

- Κάθε μάθημα ζει στον δικό του φάκελο: `/<slug>/index.html`
- Μην επεξεργάζεσαι με το χέρι το `manifest.json` — το εργαλείο το ξαναγράφει.
